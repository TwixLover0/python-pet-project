# Репозиторий с небольшими учебными проектами созданный с целью понимания и отработки базового синтакиса python 

1.Консольная игра "Горячо-Холодно" эта игра в которой нужно угадать число,если не отгадать,то выводится холодно и наоборот.Неограниченное количество 
попыток, после отгадывания выводятся сколько попыток было использовано.
Использован цикл `while`, условные операторы `if`,`elif`,ключевое слово `break`.
# Как запустить:

1.Клонируйте репозиторий:
```
git clone https://github.com/TwixLover0/python-pet-project.git
```
2.Перейдите в папку проекта:
```
cd python-pet-project
```
3.Запустите скрипт:
```
python3 project.py
```
